# AttentionItem

Doporučení v sekci Pozornost na Home (LUMI-UX-001, 009): název a jedna krátká věta proč.

**Co dodává volající:** název, krátký důvod (např. „Po termínu od 13. 10.“, „Nemá další krok“), tón důvodu (`danger` / `muted`), akce Otevřít, Odložit, Skrýt.

**Pravidla**
- Dva řádky, nic víc. Čas vyhodnocení a zdroj jsou v nápovědě nadpisu sekce a v detailu, ne u položky.
- Otevřít je vždy vidět; Odložit a Skrýt po najetí nebo fokusu (na klávesnici vždy dosažitelné), na mobilu v detailu.
- Nejvýše pět položek. Prázdný stav: sekce se nezobrazí.
