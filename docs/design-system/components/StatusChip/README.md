# StatusChip

Tichý řádek stavu pod nadpisem obrazovky – jen když je problém.

**Co dodává volající:** krátký text, úroveň (`warning` / `info`), volitelně jednu akci.

**Pravidla**
- Synchronizováno, počet v Doručených apod. se neukazuje (počty jsou v sidebaru).
- Nejvýše jeden řádek na obrazovku, tečka + slovo, bez rámečku a výplně.
